# Project Description: Friendly Coding Tutor

Friendly Coding Tutor is an AI-powered web application designed to help students, beginners, and programmers learn coding and solve technical problems easily. It provides a conversational interface similar to ChatGPT, allowing users to ask questions, understand concepts, generate code, and receive explanations in simple language.

The application offers four main features: Explain a Concept, Debug My Code, Learn with an Example, and Practice. Users can select programming languages such as Python, Java, JavaScript, C++, TypeScript, and SQL for language-specific assistance. The debugging feature helps identify coding errors and suggests corrections, while the learning feature explains programming topics through practical examples. The practice feature helps students improve their problem-solving abilities.

In addition to coding assistance, the application supports general conversations, educational questions, and writing tasks. It includes interactive chat functionality, formatted responses, code blocks, conversation history, loading indicators, and automatic scrolling for a smooth user experience.

The system uses an AI backend to generate relevant responses and provide personalized assistance. Its responsive interface is designed to work across desktop, tablet, and mobile devices.

The main objective of Friendly Coding Tutor is to make programming education easier, more interactive, and accessible. It helps users understand difficult concepts, improve coding skills, solve problems independently, and build confidence in learning new technologies through AI-powered guidance and continuous practice.
